# FOGGY Evrima Skin Studio

Static GitHub Pages frontend.

After the Railway API is deployed, edit `config.js` and replace `API_BASE` with the Railway public HTTPS URL.

The site is intended to be served at:

`https://iillifoggyiilli.github.io/evrima-skins/`

Dinosaur preview images are referenced from TheIsle.ru at runtime; no game image/model assets are copied into this repository.
